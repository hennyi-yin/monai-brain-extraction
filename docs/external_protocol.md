# External adult T1w validation protocol

Fixed on 2026-11-13 before any prediction or score on the external cases. The question is whether the frozen NFBS U-Net retains an advantage on unseen adult T1w acquisitions. This is an independent-data experiment after the original study, not a change to the NFBS analysis or a clinical validation.

## Cohorts and eligibility

Use the [official SynthStrip v1.5 3D release](https://surfer.nmr.mgh.harvard.edu/docs/synthstrip/) and its [published archive checksum](https://surfer.nmr.mgh.harvard.edu/docs/synthstrip/data/SHA256), SHA-256 `c9f070c40266790d97fce35b8864dfcd96f039b598311030c9d707671b3b0aba`. Include every entry in `scans_test.txt` matching `ixi_t1_[0-9]+` (48) or `asl_t1_[0-9]+` (41). Use the corresponding unchanged `image.nii.gz` and `mask.nii.gz`. Exclude the publisher's validation split, other sequences, and other source cohorts by this rule alone. The IXI cohort tests a different acquisition and anisotropic sampling; the adult ASL cohort adds a separate near-isotropic source. No image or label from these cohorts is used for training, calibration, or tuning of the NFBS model.

Require 89 unique subject IDs, finite images, nontrivial binary reference masks, 3D matching shape and affine, mm units, and orthogonal voxel axes for physical HD95. Verify reference and image hashes against the locked manifest and compare decompressed NIfTI hashes to the 125 NFBS inputs as an exact duplicate check. Cohort source separation and exact nonmatches are evidence for independence; this does not establish identity across archives with different pseudonyms. Missing, duplicate, invalid, or geometrically ambiguous shared inputs stop the run rather than silently shrinking the cohort.

The [reference protocol](https://doi.org/10.1016/j.neuroimage.2022.119474) starts from a majority vote of classical skull strippers and is manually refined; v1.5 additionally cleans components and holes. The references are not de novo independent delineations, may be correlated with conventional methods, and need not match NFBS boundary conventions. The publisher's test split is retained for SynthStrip; the comparison is against its own published benchmark and should not be represented as an independent replication for SynthStrip. Cite the [IXI source](https://brain-development.org/ixi-dataset/), the [ASL study](https://doi.org/10.1002/jmri.26916), and Hoopes et al. See the [publisher's license notice](https://surfer.nmr.mgh.harvard.edu/docs/synthstrip/data/README): IXI images are CC BY-SA 4.0 in this release; other content is CC BY 4.0. Source volumes and reference masks stay in ignored storage. No source-image panels or mask volumes are added to Git or published as part of this experiment.

## Frozen methods

All methods receive the same untouched whole-head image. Do not align or crop it externally, change parameters for a case, choose a method based on an external score, or train on the external data. Smoke-test only on the first NFBS training case. On the external data, generate and lock all masks before computing any score.

1. **NFBS U-Net:** epoch 190 `checkpoints/best.pt`, SHA-256 `167ecd9e5a9b6d7054052488d52ab71ab354eb83b6f382cecb45538e8f06735c`. Reuse the exact configuration and `src.data` / `src.infer` pipeline, including RAS orientation, nonzero z-normalization, 96³ sliding windows, original inference precision, native spacing (no resampling), largest component, hole fill, and inverse orientation. No checkpoint reselection.
2. **BET -R:** exact prior FSL build, `bet <image> <output> -f 0.5 -R -m -n`, no external crop.
3. **robustfov + BET -R (primary comparator):** exact prior FSL executables; `fslreorient2std`, `robustfov -b 170`, then the same BET command. Reuse the prior nearest-neighbor map-back and geometry checks (including the declared FLIRT fallback). The crop diagnostic is measured only during scoring and never used to edit a prediction.
4. **SynthStrip (secondary learned comparator):** default CSF-inclusive FreeSurfer 7.4.1 implementation `mri_synthstrip` and `synthstrip.1.pt`, with `-b 1` and `-m`. Pin the script SHA-256 `d674926f56393e3ead4eeb4a53a3b41de16f822469d653e33cdfe9d69c3185a2` and weight SHA-256 `37417f802196186441aae3e7f385d94f8a98c64a88acaeaa2723af995c653e33`. It may run under the current PyTorch CUDA runtime if the bundled runtime cannot use the GPU; the script and weights are unchanged. Select the working backend on the NFBS smoke only and record it. This is SynthStrip, not the older FreeSurfer `autorecon1` watershed baseline, which remains an NFBS-only result in this study.

Check each output's native shape/affine, binary values, and dtype. Save binary uint8 in the original grid. Only a subject-specific command error, invalid geometry/mask, or empty prediction becomes an empty mask with Dice 0 and HD95 infinity; keep it in the denominator and log it. A shared environment/tool problem stops the run. Never rerun an external prediction to improve a result. An interrupted process may resume unattempted cells; any cell interrupted after its attempt started is recorded as failed and not rerun.

## Endpoints and reporting

Use the existing foreground Dice and symmetric physical HD95 definitions in `src.metrics`, reference threshold ≥0.5. Primary contrast: paired Dice **U-Net minus robustfov + BET -R** in each cohort, with the equal-subject-weight pooled contrast as the primary summary. Use 10,000 paired bootstrap resamples, seed 42, percentile 95% intervals for mean Dice differences; for the pooled interval resample subjects within each cohort and keep cohort sizes fixed. Provide mean ± sample SD, median, minimum, counts below Dice 0.8 and with zero overlap, HD95 median/IQR including infinity, and execution failure counts per method/cohort. Also report secondary paired mean/median differences, intervals, wins/ties/losses against all comparators. Interpret intervals descriptively and acknowledge multiple contrasts; do not claim universal superiority. Show paired differences by cohort and a paired comparison table, retaining all low-scoring subjects. Compare NFBS and external summaries descriptively only; their label protocols and acquisition populations differ.

Lock source archive, split list, 89 input pairs, model, binaries, configuration, and outputs by SHA-256. Separate prediction from scoring and retain one scoring pass per subject-method pair. Verify the 202 previously frozen files, 38 additional FreeSurfer files, and all three existing README result sections by SHA-256. Store the external manifest, case scores, protocol, audit, and figures separately.
