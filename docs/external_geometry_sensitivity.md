# Post-hoc external crop map-back sensitivity

During locked external prediction, before viewing external scores, several ASL scans failed the pre-declared crop-footprint check. The existing FLIRT fallback could map identical overlapping ROI intensities and preserve BET foreground count, yet omit a native boundary slice of the crop footprint. The primary protocol and its empty-mask handling are unchanged.

This separate sensitivity analysis asks whether these failures alter the U-Net versus cropped BET comparison. It does not rerun BET, robustfov, or any other model. Consider only primary cropped BET failures explicitly recorded as a failed native crop map-back with saved ROI and raw BET mask. Reorient the saved ROI and mask to the native axis ordering; require an integer translation and identity linear transform after reorientation within 0.001 voxels at all eight corners. Require full in-bounds placement and exact equality to the native intensities across the entire placed crop, including zeros. Require a nonempty binary mask with preserved foreground count. Use direct voxel assignment if all checks pass. Otherwise retain the primary failed result. Record hashes of the saved inputs and geometry evidence. Do not use the reference to select the map or accept a recovery.

Score each recovered new native mask once with the same metrics, and copy the other cropped BET rows verbatim from the locked primary CSV. Use the same paired, stratified bootstrap and report all unrecovered failures. This is a diagnostic based on observed geometry failures, not a replacement for the pre-declared result. If the conclusions differ, report both prominently.

Before external scoring, the raw-header investigation also identified IXI images with scaled integer voxels: `robustfov` stores their ROI as float32, while NiBabel's default proxy decodes the native intensities as float64. For a stored float32 ROI, compare its values to the native crop after one explicit float32 cast. Require exact equality in that storage representation, with no numerical tolerance, and record whether equality was also exact before casting. The corner, bounds and foreground checks are unchanged. This addresses intensity representation rather than changing the segmentation or any primary rule.
